# 教训记录

每条教训带触发条件、现象、原因、原因可信程度（已验证附证据｜假设）、
处理办法、验证证据与适用范围。不把一次偶然失败写成永久禁令。

铁律准入：一条教训进正式集必须同时满足——能对应一个真实发生过的失败
（附原料或汇总编号）、处理办法写成可执行的检查而非口号、给出验证方法。
达不到的留在原料语义段里，不许升格。失效教训标「已被 L-xx 取代」或「已过期」，不删除。

死胡同记录：每个被放弃的方案记四字段——试法／为何试／确切失败证据（报错原文或失败测试名）／
重试条件（什么变了才值得重试）。接手时若重试条件可能已变化，用最便宜的命令复验；
验不了就标「未复验、结论可能过期」，不许继续引为可信事实。
