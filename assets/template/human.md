# 人的使用说明

新项目：对已安装“项目接力”Skill 的 agent 说：“使用 project-relay 初始化这个项目，先阅读现有资料，再建立 .agent。”

以后接手：对任何能读写项目文件的 agent 说：“先阅读 .agent/agent.md，按索引了解现状，然后继续〔你的任务〕。每完成一个有意义步骤就更新记录。”

收尾：“保存本次可获得的聊天原文；没有原文则保存详细交接摘要，更新当前状态和下一步。”

检查：“核对 .agent 的描述与实际项目是否一致，指出过时内容并按证据修正。”

Skill 不会自动监听文件夹。根目录的工具入口可帮助支持它们的工具发现协议；其他工具直接指定读取路径即可。仅能聊天、不能访问本地文件的工具，需要你上传相关文件或提供访问能力。

迁移同一项目时一起带走项目和 .agent；初始化另一个项目用干净模板。框架兼容多种项目，但第一版只支持 agent 轮流接手。跨工具读取 Markdown 不等于各工具都支持相同 Skill 安装方式。
